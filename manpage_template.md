# NAME

suv -- a mini helper tool for supervisions of academic papers

# SYNOPSIS

**suv** [*OPTION*]

# DESCRIPTION

**suv** reads through all ...

Without parameter, "suv" will ask you what you would like to do.

With the parameter "add," it will let you enter structured data for a new supervision (name of the candidate etc. will be asked of you).

The parameter "list," will list active ...
